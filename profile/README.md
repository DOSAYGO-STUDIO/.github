# DOSAYGO STUDIO

Welcome to **DOSAYGO STUDIO** — an innovative software development organization creating cutting-edge tools spanning secure browsing, cryptography, quantum computing research, and mathematical exploration.

🌐 **Website:** [dosaygo.com](https://dosaygo.com)

## 🎯 Mission & Focus

DOSAYGO STUDIO develops open-source and commercial solutions that push the boundaries of:

- **Secure Remote Browsing** — Remote browser isolation and secure document handling
- **Cryptography & Hashing** — Fast, efficient cryptographic primitives
- **Mathematical Research** — Novel number representations and organizational metrics
- **Quantum Computing** — Theoretical quantum communication research
- **Security Tools** — OSINT, device tracking, and privacy protection

## ⭐ Featured Projects

### 🌐 Remote Browser Isolation

#### **BrowserBox**
Enterprise-grade remote browser isolation platform with 60 FPS streaming, cross-platform support, and clientless operation. Designed for healthcare, finance, and regulated industries with HIPAA and NIST compliance.

- 🔗 [BrowserBox Website](https://browserbox.io/)
- 📦 Commercial product with automation support (Playwright/Puppeteer)
- ✨ Features: PDF viewing, DevTools access, team browsing, data leakage prevention

### 🎵 Generative Music & Creative Code

#### **Less Talk**
An original big-beat homage in Web Audio. Two synthesized voices keep talking; the band keeps getting louder until the brass shuts them down. One HTML file, no libraries, everything synthesized.

- 🔗 [Play it](https://dosaygo-studio.github.io/less-talk/) | [Repository](https://github.com/DOSAYGO-STUDIO/less-talk)
- 🥁 Breakbeats, wah guitar, organ, bass and a brass section, all oscillators and noise
- 🗣️ Formant "talkers" in speech bubbles that pop when the drop lands

### 📰 Data & Archive Projects

#### **HackerBook**
Static, offline-friendly archive of Hacker News running entirely in your browser via SQLite WASM. Search and time-travel through HN history with no backend required.

- 🔗 [Demo](https://hackerbook.dosaygo.com) | [Repository](https://github.com/DOSAYGO-STUDIO/HackerBook)
- 💾 Sharded SQLite databases for fast client-side queries
- 🛠️ ETL scripts to refresh from HN BigQuery dataset
- 📜 **License:** MIT (YC & authors retain HN content rights)

#### **prime-news**
Hacker News filtered to show only items with prime number IDs, featuring Mersenne primes, Fermat primes, palindromic primes, and more.

- 🔗 [Demo](https://dosaygo-studio.github.io/prime-news/) | [Repository](https://github.com/DOSAYGO-STUDIO/prime-news)
- 🔢 Uses Prime Number Theorem for jump-to-prime navigation
- 🔥 Live data from HN's Firebase API with SQLite WASM queries

### 🔐 Cryptography & Hashing

- ⚡ C++ and NodeJS/WASM APIs
- 🎯 Optimized for speed, compactness, and cryptographic applications
- 🛠️ CLI and library usage

#### **novel-hashing-concepts**

- 🚀 Cutting-edge cryptographic exploration

### 🔢 Mathematical Research

#### **irradix**
Novel binary representation of integers using Base-φ (phi, the golden ratio).

- 🔗 [Repository](https://github.com/DOSAYGO-STUDIO/irradix)
- 📐 JavaScript implementation exploring mathematical properties
- 📜 **License:** Apache-2.0
- 🌟 Conceptual research in number theory

#### **structropy**
Exploration toward defining "a metric of organization" for structuring information.

- 🔗 [Repository](https://github.com/DOSAYGO-STUDIO/structropy)
- 📝 TeX-based theoretical work
- 🧠 Information theory and systems science

### ⚛️ Quantum Computing

#### **quacomms**
Quantum communication proposal leveraging stochastic Bohmian mechanics for entanglement-based retrocausal signaling.

- 🔗 [Repository](https://github.com/DOSAYGO-STUDIO/quacomms)
- 🐍 Python simulations using QuTiP
- 📄 Includes white paper and research documentation
- 🔬 Highly speculative theoretical research
